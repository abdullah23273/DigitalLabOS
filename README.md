# Digital Lab Operating System Simulator

## Overview
This project simulates core Operating System components including memory management, file system, disk scheduling, and security enforcement in a multi-user environment.

## Features
- Paging system with LRU page replacement
- Disk scheduling using SCAN algorithm
- Hierarchical file system simulation
- Role-based access control (Admin, Student, Guest)
- System-wide logging mechanism

## Technologies
- Python 3
- Command Line Interface
- File handling (logging system)

## Modules
1. Memory Management (LRU)
2. File System (CRUD operations)
3. Disk Scheduling (SCAN)
4. Security System (RBAC)
5. Logging System
